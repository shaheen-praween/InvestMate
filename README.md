# InvestMate — Virtual Stock Trading & Investment Management System

A full-stack web application that simulates stock trading with virtual money.
Users get ₹1,00,000 virtual cash to trade, manage a portfolio, track a watchlist
and view analytics. Includes an admin panel.

> This is a virtual trading simulation only. No real money, no real market orders.

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Chart.js
- Backend: Node.js, Express.js
- Database: MongoDB with Mongoose
- Auth: JWT, bcrypt
